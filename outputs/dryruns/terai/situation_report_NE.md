# स्थिति प्रतिवेदन (प्रारम्भिक) — terai, २०२६-०८-२६

> प्रारम्भिक: २०२६-१०-१२ मा पाइपलाइनका JSON फाइलबाट स्वतः बनाइएको (commit `unknown` (git state unknown))। शैक्षिक प्रोटोटाइप, सञ्चालनमा प्रयोग गर्ने उपकरण होइन।
> अनुवाद मेसिन-सहायतामा गरिएको हो; नेपाली भाषीले जाँच गर्नुहोस्। अंक अंग्रेजी प्रतिवेदन (situation_report_EN.md) सँग मिल्छन्।

**अवस्था।** Sentinel-1 (Planetary Computer RTC gamma0 (GRD बाट तेस्रो पक्षले प्रशोधन गरेको), क्रस-जाँच मात्र) २०२६-०८-१६ / २०२६-०८-२८, ट्र्याक asc85। डिटेक्टरको नतिजा: **उल्लेखनीय परिवर्तन छैन (no_significant_change)** — क्यालिब्रेसन लक्ष्य पूरा भएन (calibration target not met); न्यूनतम पत्ता लाग्ने क्षेत्र ≈ १७ वर्ग कि.मि.। यो उपत्यकाको सतहमा पत्ता लागेको परिवर्तनसँगको **जोखिम (exposure)** हो, पुष्टि गरिएको बाढी क्षेत्र होइन र क्षति होइन। "बाढी-जस्तो" वर्ग भनेको पानी-जस्तो ब्याकस्क्याटर परिवर्तन हो, खुला पानी पुष्टि भएको होइन। पुलहरू जोखिममा छन् भनिएको हो, भत्किएको होइन।
